# DPI Device Development & Design Control

DPI装置研发与设计控制模板库（Draft v0.1）。覆盖ISO 13485设计开发控制、ISO 14971风险管理、设计输入、双向追溯、阶段门、验证确认、工程变更及DHF。

## 目录
- `00_Governance/` 文件与设计控制
- `01_Design-Planning/` 设计开发策划
- `02_Design-Inputs/` 用户需求与设计输入
- `03_Risk-Management/` 风险管理
- `04_Design-Outputs/` 设计输出索引
- `05_Traceability/` 需求追溯
- `06_Verification-Validation/` 验证与确认
- `07_Design-Reviews/` 阶段门
- `08_Change-Control/` 变更控制
- `10_DHF/` 设计历史文件索引
- `projects/DPI-PLATFORM-001/` 试点项目

## 使用要求
所有文件均为未批准草案；TBD项必须经评审确定。GitHub版本历史/PR不能替代公司QMS批准、记录控制或合规电子签名。若仓库公开，禁止上传保密图纸、配方、供应商资料、临床数据和真实受控记录。
